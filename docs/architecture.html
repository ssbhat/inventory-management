Architecture overview

Factory Inventory Management System

A full-stack demo app for tracking inventory, orders, demand, backlog and spending across factory warehouses. A Vue 3 single-page app talks to a FastAPI server that serves mock data from JSON files kept in memory. There is no database.

Data flow: changing a filter

What happens when a user picks, say, "Q3-2025" and "Sensors" in the filter bar.

FilterBar.vue

User picks a filter

The filter bar writes to four shared refs: period, location, category and status.

composables/useFilters.js

Shared state updates every view

The refs live at module level, so every component that calls useFilters() sees the same values. getCurrentFilters() turns them into an API object, mapping location to warehouse and period to month.

views/*.vue → api.js

View watches filters and requests data

The view calls a method such as api.getOrders(filters). api.js drops any value equal to "all" and builds the query string.

GET /api/orders?month=Q3-2025&category=Sensors

FastAPI filters the in-memory lists

apply_filters() matches warehouse exactly and category and status case-insensitively. filter_by_month() expands a quarter to its three months and matches them against order_date.

server/main.py

Pydantic validates the response

The endpoint's response_model checks the shape and serialises the result to JSON. Dashboard totals are calculated on the fly per request.

ref → computed → template

Vue re-renders

Raw data lands in refs (allOrders, inventoryItems). Charts, KPIs and tables are computed properties built from those refs, so they update automatically. Currency follows the language: USD for English, JPY for Japanese.

Things to know

Found while reading the code.

The client calls endpoints that don't existapi.js calls /api/tasks and /api/purchase-orders, but main.py has no routes for them. App.vue's task list and the backlog purchase-order flow will get 404 or 405 errors.
Backlog view isn't routedviews/Backlog.vue exists but isn't registered in main.js. Backlog data only shows on the Dashboard.
Nothing is savedData is read once when the server starts. A restart resets everything, and nothing writes back to the JSON files.
Quarter filters only cover 2025QUARTER_MAP is hard-coded for Q1 to Q4 2025. Unknown quarters fall through and return unfiltered data.
Demo-grade securityNo authentication. CORS allows all origins and the "logged-in user" is a hard-coded mock in useAuth.js. The repo is public, so never commit secrets.
